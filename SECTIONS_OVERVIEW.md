## 🎨 Visual Design Elements

### Color Scheme

**Light Mode:**
- Background: White (#ffffff)
- Text: Near-black
- Primary: Dark (#030213)
- Cards: White with subtle shadow
- Borders: Light gray (rgba(0,0,0,0.1))

**Dark Mode:**
- Background: Very dark gray
- Text: Near-white
- Primary: White
- Cards: Dark gray with borders
- Borders: Medium gray

### Section Alternation
- White sections: Hero, About, Projects, Contact
- Gray sections: Experience, Skills, Footer
- Creates visual rhythm and separation

### Card Patterns
All cards follow the same design:
- Rounded corners (0.625rem)
- Subtle border
- Padding: 1.5rem (24px)
- Hover: Shadow increase + slight lift
- Smooth transitions

---

## 📏 Spacing System

### Vertical Spacing
- Section padding: 5rem (80px) → 8rem (128px) on desktop
- Between elements: 2rem (32px)
- Heading margin bottom: 3rem (48px)
- Card gaps: 1.5rem (24px)

### Horizontal Spacing
- Container max-width: 1024px (5xl)
- Padding: 1rem (mobile) → 2rem (desktop)
- Card padding: 1.5rem (24px)

### Responsive Breakpoints
- Mobile: < 640px (base styles)
- Tablet: 640px - 768px (sm:)
- Desktop: 768px - 1024px (md:)
- Large: 1024px+ (lg:)

---

## 🎭 Interactive States

### Navbar
- **Scroll**: Background blur + border appears
- **Hover**: Links scale up slightly
- **Active**: Animated underline indicator moves

### Cards
- **Default**: Border, subtle shadow
- **Hover**: Lift (-4px), shadow increase, border color shift
- **Focus**: Ring outline for keyboard navigation

### Buttons
- **Hover**: Background darkens, scale 1.02
- **Active/Press**: Scale 0.98
- **Focus**: Ring outline

### Copy Buttons
- **Click**: Icon changes to checkmark
- **Feedback**: Toast notification appears
- **Reset**: Returns to copy icon after 2s

---

## 📱 Responsive Behavior

### Mobile (< 768px)
- Hamburger menu instead of nav links
- Stacked buttons and CTAs
- Full-width cards
- Timeline line hidden
- Single column layout

### Tablet (768px - 1024px)
- Some nav links visible
- Two-column grids where appropriate
- Timeline line appears
- Larger spacing

### Desktop (1024px+)
- Full navigation visible
- Three-column skill grid
- Maximum container width
- All spacing at full size

---

## ✨ Animation Sequence

### On Page Load
1. Navbar slides down (duration: 300ms)
2. Hero section fades in (duration: 500ms, staggered)
   - Name appears first
   - Then title
   - Then location
   - Then chips
   - Finally CTAs

### On Scroll
1. Section heading fades in + slides up
2. Content animates 100ms after heading
3. Lists/cards stagger (100ms between items)
4. Hover effects always active

### On Interaction
- Button press: Scale down (98%)
- Card hover: Lift up + shadow
- Copy: Icon swap + toast
- Theme toggle: Icon rotation

## 🎯 User Journey

### First-Time Visitor
1. Lands on hero → Sees name, title, location
2. Reads quick facts → Gets instant overview
3. Scrolls to About → Learns background
4. Reviews Experience → Sees work history
5. Explores Projects → Understands capabilities
6. Checks Skills → Confirms technical expertise
7. Contacts → Reaches out via preferred method

### Returning Visitor
- Uses navbar to jump directly to section of interest
- Dark mode preference is remembered
- Quick access to CV download
- Copy buttons for easy contact info

### Mobile User
- Hamburger menu for navigation
- Touch-friendly tap targets (min 44px)
- Readable text without zooming
- Smooth scrolling between sections
